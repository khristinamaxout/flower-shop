# Панель управления сайтом

Через панель можно добавлять товары, менять цены, загружать фотографии
и редактировать условия доставки. Изменения появляются на сайте сразу —
пересобирать и заново публиковать сайт не нужно.

Адрес панели: **адрес сайта + `/admin.html`**
(например `https://khristinamaxout.github.io/flower-shop/admin.html`).

Ссылки на панель на самом сайте нет — её видят только те, кому вы дали адрес.

---

## Что уже настроено

Эти шаги выполнены, повторять не нужно — они описаны на случай,
если понадобится восстановить или перенести проект.

- **Проект Supabase** — `flower-shop`, регион Central EU (Frankfurt).
- **Таблицы и хранилище фотографий** — создан запросом из файла
  `supabase/schema.sql` через **SQL Editor** → вставить текст → **Run**.
- **Ключи в коде** — прописаны в `src/data/supabase-config.js`.
  Берутся в Supabase: **Project Settings** → **API Keys** →
  **Project URL** и **Publishable key** (в старых проектах он назывался
  `anon public`).

> Publishable key не секретный: он разрешает только **читать** каталог,
> именно так сайт показывает товары посетителям. Менять данные может лишь
> тот, кто вошёл в панель по паролю.
>
> А вот ключ `sb_secret_...` с той же страницы — полностью секретный.
> Его нельзя вставлять в код и никому пересылать.

## Первичная настройка

### Шаг 1. Создать доступ в панель

1. В Supabase откройте **Authentication** → **Users**.
2. Нажмите **Add user** → **Create new user**.
3. Введите почту и пароль заказчицы.
4. Обязательно включите галочку **Auto Confirm User** — иначе вход
   работать не будет.
5. Нажмите **Create user**.

Если понадобится дать доступ ещё кому-то — добавьте второго пользователя
здесь же.

### Шаг 2. Перенести каталог

1. Откройте `/admin.html` и войдите с созданными почтой и паролем.
2. Панель увидит, что база пуста, и предложит **«Перенести готовый каталог»** —
   нажмите эту кнопку. Все 16 товаров, которые сейчас на сайте, попадут в базу,
   и их можно будет редактировать.

### Шаг 3. Опубликовать

Чтобы подключение к базе попало на живой сайт:

```powershell
cd "c:\Users\User\Desktop\Мой бизнес\Сайты\Цветочный магазин"
git add -A
git commit -m "Подключить панель управления"
git push
```

Через 2–3 минуты панель заработает по адресу сайта.

## Как пользоваться

### Добавить товар

Вкладка **Товары** → кнопка **+ Добавить товар**.

Заполните название, категорию и цену, добавьте фотографию — этого достаточно.
Остальные поля можно оставить пустыми и дополнить позже.

### Загрузить фотографию

В форме товара нажмите **Выбрать фото с устройства** или перетащите файл
в серую рамку. Подойдут JPG, PNG и WebP.

Снимок с телефона можно загружать как есть: панель сама уменьшит его
до нужного размера, чтобы сайт не тормозил. Фотография отправляется
на сервер в момент нажатия **Сохранить**.

Если своего фото пока нет, кнопка **Взять из готовых** открывает набор
изображений, которые уже есть на сайте.

### Изменить цену

Вкладка **Товары** → **Изменить** у нужной строки → поле **Цена** →
**Сохранить изменения**.

Поле **Цена до скидки** заполняйте, только если хотите показать скидку:
на карточке появится зачёркнутая старая цена.

### Временно убрать товар с сайта

Если цветы закончились, не удаляйте товар — выключите переключатель
в столбце **На сайте**. Товар исчезнет со страницы, а все его данные
и фотография сохранятся. Когда снова появится в наличии, включите обратно.

**Удалить** стирает товар навсегда, отменить это нельзя.

### Разделы на главной

Галочки **Разделы на главной** определяют, в какие блоки попадёт товар:
«Выбирают чаще всего», «Новая коллекция» и другие. Товар может быть
сразу в нескольких разделах.

Галочки **Кому подойдёт** и **К какому поводу** нужны для подборщика
подарка на главной странице — по ним он предлагает букеты.

### Условия доставки

Вкладка **Доставка** — здесь меняется текст блока «Доставка» на главной:
заголовок, подзаголовок и список условий (время работы, сроки, курьер).
Условие можно удалить крестиком или добавить новое кнопкой ниже.

## Если что-то не работает

**«Неверная почта или пароль»** — проверьте раскладку клавиатуры. Если
не помогает, в Supabase → Authentication → Users найдите пользователя,
нажмите на него и задайте новый пароль.

**«Нет прав на изменение»** — сессия истекла. Нажмите **Выйти** и войдите
заново.

**«Нет связи с сервером»** — проверьте интернет. Если интернет есть,
зайдите в Supabase: бесплатный проект засыпает после недели без обращений,
и открытие панели его будит.

**Изменения не видны на сайте** — обновите страницу сайта с очисткой кэша:
Ctrl+F5 на компьютере, потянуть страницу вниз на телефоне.

**Панель пишет «Админка ещё не подключена»** — опустел файл
`src/data/supabase-config.js`, см. раздел «Что уже настроено».

## Что происходит при сбое

Если сервер недоступен, сайт не ломается: он покажет последний удачно
загруженный каталог из памяти браузера, а если и его нет — встроенный
набор товаров. Посетитель в любом случае увидит рабочий магазин.
